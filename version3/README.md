# MPS PRO · Version 3

기존 mps-centers2 기능을 MPS PRO 대시보드 스타일로 구성한 세 번째 디자인 샘플입니다.

- 실행: index.html
- 다크 미리보기: index.html?theme=dark
- 라이트 미리보기: index.html?theme=light
- 일출·일몰 자동: index.html?theme=auto (기본값, 서울 기준)
- 12명 가상 선수, 성장단계별 2명
- 선수 상세, 레슨 완료·취소, IDP 목표, 예약, Google 일정별 수동 추가

색상은 참고 대시보드의 차콜 #191919, 패널 #2c2c2c, 청록 #00b3ed, 보라 #9b8cff, 그린 #81ce82, 샌드 #c7b38b를 사용합니다. 라이트 화면에는 주황색을 사용하지 않습니다.

선수와 예약 데이터는 같은 도메인의 기존 샘플과 공유합니다. 테마 설정은 버전별로 저장합니다. 모든 데이터는 브라우저 저장 샘플이며 서버·계정·의료 결과·실제 결제 연동은 없습니다.

검증: 선수 12명 및 단계별 분포, 레슨 완료·취소, IDP 저장, 예약 선택 유지·복귀, 계절별 자동 테마 로직. 모바일·PC 정적 렌더 확인. 실제 iPhone Safari 실기기 검증은 수행하지 않았습니다.
